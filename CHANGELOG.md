## [0.1.0] - 2026-11-26

### Added

- Initial Unity Package Manager layout for Brickpad Proto-Catalog (`com.brickpad.protocatalog`), targeting Unity 6000.0.
- Runtime assembly `Brickpad.ProtoCatalog` and editor-only assembly `Brickpad.ProtoCatalog.Editor`.
- Play Mode and Edit Mode test assemblies, each with a smoke test.
- Placeholder sample registered in the package manifest.
- Module layout convention and the quality bar for promoting a prototype into the catalog.
